# Assumptions Register

Every design-relevant assumption that has **not** been verified end to end is listed here, with its evidence, the risk
if it is wrong, and the fallback we build in. When an assumption is settled, its row is updated in place: set the
Status to `CONFIRMED` or `REFUTED`, add the date and evidence, and keep the row for traceability. Never delete a row.

- Referenced from [LMU_TELEMETRY_RESEARCH.md](LMU_TELEMETRY_RESEARCH.md) and [LMU_CHANNEL_MAP.md](LMU_CHANNEL_MAP.md) as `A-LMU-nnn`.
- Evidence labels follow the research doc: VERIFIED (observed here), VERIFIED-SOURCE (official doc or project code), INFERRED, CLAIMED (third party), UNVERIFIED.
- "Gate-1 check" means the runtime diagnostic `tools/lmu-diag` run against a live LMU. It is listed in LMU_TELEMETRY_RESEARCH.md §13.
- **Later phases append their own sections below the LMU section.** Use a new prefix per area, for example `A-NET-`, `A-REC-`, `A-UI-`, `A-ENG-`.

Baseline for every LMU row:
- LMU 1.4.2.0, Steam build 25513257.
- Headers fingerprinted in `docs/research/lmu_headers_fingerprint.json`.
- Static research dated 2026-09-30. **LMU was not running**, so every row is `OPEN` until the Gate-1 check.
